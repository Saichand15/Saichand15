### 🎯 LottoLens — Lottery Pattern Analysis Platform

</div>

> **A full-stack React application** that implements a novel **Beam Touch Arithmetic Prediction** methodology for lottery number analysis, backed by 1,700+ historical draws.

| Layer | Technology |
|-------|-----------|
| **Frontend** | React 18 + Vite, React Router v6, Recharts |
| **Database** | Supabase (PostgreSQL) — live draw storage & querying |
| **AI** | OpenAI API via Netlify Serverless Functions |
| **Deployment** | Netlify (CI/CD, edge functions) |
| **Data** | 343+ LottoLens draws + 1,346 Powerball draws |

**✨ Key Features:**

- 📊 **Interactive Matrix Grid** — 2D heatmap (numbers × draws) with gap-based heat coloring
- 🔭 **Laser Beam Overlay** — SVG-rendered directional beam paths (NW/NE/SW/SE compass)
- 🤖 **AI Chat Assistant** — context-aware lottery analyst powered by OpenAI
- 📈 **Multi-Engine Prediction** — independent engines for LottoLens (1–45) and Powerball (1–69)
- 🎫 **Ticket Builder** — click-to-pick interface with score-ranked candidates
- 📉 **Backtesting** — automated validation against the last 10 historical draws
- ☁️ **Resilient Data Layer** — Supabase primary + JSON fallback strategy
